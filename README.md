# คุยลึก ๆ ข้ามระยะทาง · Husky & Munchkin Deep Talk

เกมการ์ดคำถามสำหรับคู่รักทางไกล 270 ใบ 9 หมวด แต่ละใบมี 3 ภาษา (ไทย / English / 日本語 พร้อมฟุริกานะ)
Deep-talk question cards for long-distance couples, playable in any browser.

## เล่น / Play

เปิดลิงก์ GitHub Pages ของ repo นี้ หรือดาวน์โหลดแล้วเปิด `index.html` (เล่นออฟไลน์ได้)

- ระดับความลึก 1–3 ต่อใบ โหมด "เบาไปลึก"
- เลขการ์ด: เปิดใบเดียวกันทั้งสองเครื่องระหว่างคอล
- นาฬิกาสองฝั่ง, ปุ่มฟังเสียงภาษาญี่ปุ่น (ใช้เสียงในเครื่อง)
- เขียนการ์ดเอง และส่งให้แฟนเป็นโค้ด

## ไฟล์ / Files

| ไฟล์ | คืออะไร |
| --- | --- |
| `index.html` | ตัวเกม |
| `questions.js` | คำถามทั้งหมด หนึ่งบรรทัดต่อหนึ่งใบ เพิ่มใบใหม่ต่อท้ายเท่านั้น เลขการ์ดจะได้ไม่เลื่อน |
| `art.js` | ภาพสีน้ำของฮัสกี้ แมว และของตกแต่ง (วาดด้วย SVG ไม่มีไฟล์รูป) |
| `fonts/` | ฟอนต์ Mali (SIL Open Font License) |

รูปแบบคำถาม: `["หมวด", ความลึก 1-3, "ไทย", "English", "日本語 {漢字|かんじ}"]`
